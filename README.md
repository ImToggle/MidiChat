# MidiChat

A client-side [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat) addon that lets you play music using MIDI inputs

## Features

- Supports all note block instruments
- Configurable volumes

## How to use the mod

- Plug in your MIDI device then run ``/midi rescan`` command
- Run ``/midi instrument <>`` to switch instrument
- Access the config menu from [Mod Menu](https://modrinth.com/mod/modmenu)
